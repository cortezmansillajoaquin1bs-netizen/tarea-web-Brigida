🎯 1. RESUMEN EJECUTIVO Y MODELADO DEL ENTORNO
El presente ecosystema informático ha sido diseñado bajo los más estrictos estándares de ingeniería de software frontend. Su propósito fundamental es la abstracción, modelado y resolución de fenómenos del mundo real a través de estructuras algorítmicas discretas.

A nivel metodológico, el proyecto erradica las prácticas obsoletas de programación monolítica, adoptando un enfoque de Desacoplamiento Estructural Absoluto. Esto significa que cada byte de información está segmentado según su naturaleza:

Capa del Esqueleto Lineal (HTML5 Semántico): Garantiza la accesibilidad universal, el indexado limpio y la estructura de nodos jerárquica.

Capa de Estilizado Dinámico y Fluidez (CSS3 Avanzado): Controla la estética visual corporativa e implementa transformaciones en tiempo de ejecución a través de técnicas de diseño responsivo de alto impacto.

Capa Lógica de Cómputo (JavaScript Motor ES6+): Gobierna el procesamiento matemático puro, las estructuras de control repetitivas y la mutabilidad dinámica del árbol del DOM (Document Object Model).

📂 3. Análisis Técnico: ¿Qué hace cada archivo HTML?
index.html (Raíz): Actúa como el portal de control central (Dashboard). Estructura el encabezado con la información académica, la materia e introduce las tarjetas de navegación hacia los sub-módulos. Aloja el pie de página con enlaces formales directos.

problema1/index.html: Interfaz del módulo criptográfico. Provee un marco teórico extenso sobre la relación entre números primos y seguridad asimétrica, además de un formulario nativo estructurado con inputs numéricos validados y restringidos.

problema2/index.html: Aloja la documentación y estructura conceptual del simulador económico de fondos indexados progresivos para mitigar la devaluación monetaria. Provee los nodos receptores para los desgloses tabulares de saldos.

problema3/index.html: Establece la base documental del laboratorio biológico virtual. Recrea los supuestos de reproducción de poblaciones celulares descritos originalmente por Leonardo de Pisa y define la sección de censo dinámico.

🎨 4. Análisis Técnico: ¿Qué hace cada archivo CSS?
css/estilos.css (Raíz): Diseña una interfaz contemporánea oscura mediante variables CSS (:root). Utiliza CSS Grid adaptativo (repeat(auto-fit, minmax(280px, 1fr))) para reordenar las tarjetas del menú dinámicamente según la pantalla.

problema1/css/estilos.css: Estiliza los componentes del reporte criptográfico. Define clases condicionales como .es-primo para destacar visualmente en color verde esmeralda los números que aprueban los filtros de seguridad informática.

problema2/css/estilos.css: Gobierna la presentación de las planificaciones financieras. Diseña filas limpias con bordes divisorios e incluye el formateo de la caja resumen contable (.total-box) en color azul destacado.

problema3/css/estilos.css: Aplica una identidad visual temática orientada a laboratorios mediante tonalidades verde azuladas (Teal), estructurando reportes visuales con bordes laterales gruesos que simulan bitácoras impresas.

⚙️ 5. Análisis Técnico: ¿Qué hace cada archivo JavaScript?
js/script.js (Raíz): Escucha el ciclo de vida del navegador (DOMContentLoaded), captura el nodo del título principal y le inyecta dinámicamente efectos de sombreado luminoso (text-shadow) cuando el usuario interactúa con el cursor.

problema1/js/script.js: Motor analítico del primer módulo. Captura el input del formulario, aplica validaciones y calcula la serie de Fibonacci usando variables simples de desplazamiento continuo (a, b, c), respetando la restricción de no usar arreglos. Procesa cada número en un bucle repetitivo de residuo modular (%) para comprobar su primalidad e inyectar el HTML formateado.

problema2/js/script.js: Administra el cómputo financiero del ahorro. Emplea la base iterativa de Fibonacci para deducir la cuota del mes, sumando de forma paralela los montos en una variable acumuladora global (totalAhorrado += depositoActual) para imprimir el capital neto de cierre.

problema3/js/script.js: Opera el simulador biológico calculando mediante ciclos iterativos elementales la cantidad absoluta de especímenes y bacterias activas en generaciones específicas, traduciendo la información matemática en censos visibles dentro del DOM.

📱 6. Ingeniería de Diseño Responsivo Avanzado
La adaptabilidad fluida de la plataforma se logra de manera 100% nativa (sin frameworks como Bootstrap o Tailwind) mediante el uso de Media Queries condicionales:

Modo Escritorio (Ancho > 768px): Entorno oscuro Deep Blue (#0f172a), distribución tridimensional en cuadrículas (3 columnas) y tipografías limpias Sans-Serif.

Modo Tablet (Ancho entre 481px y 768px): Transmutación automática del fondo a tonos pasteles o lila y colapso dinámico de la cuadrícula a 2 columnas para optimizar el espacio horizontal.

Modo Móvil / Celular (Ancho <= 480px): ¡Inversión radical de contraste a fondo claro! La cuadrícula se disuelve a una sola columna vertical, los botones se expanden al 100% para facilitar la ergonomía táctil y ocurre una mutación tipográfica completa a fuentes Serif clásicas (Georgia o Cambria), cumpliendo con las pautas de diseño avanzado.
